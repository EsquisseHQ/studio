# Code of conduct

Creators, developers and people contributing with agents are welcome here. These rules apply in Esquisse issues, discussions, pull requests and reviews.

- **Critique the work.** “The receipt shows a different price from the quote” gives someone a problem to fix. Insults, harassment, threats and discriminatory remarks have no place here.
- **Share examples you have permission to publish.** A cropped screenshot or a made-up prompt can explain a bug. Remove API keys, private messages and identifying details before you post.
- **Respect other contributors’ time.** Check for an existing issue before opening another. If you use an agent, review what it submits, say which checks actually ran and be available to answer follow-up questions.

Use the **…** menu on abusive content to report it to the repository maintainers. The maintainer can ask for an edit, remove content or limit participation when needed. If the report concerns the maintainer, you can [report it directly to GitHub](https://support.github.com/contact/report-abuse).

Found a security flaw? Use the [private security reporting channel](SECURITY.md).
