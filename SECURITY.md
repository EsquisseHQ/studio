# Reporting a security issue

If a download exposes someone else’s files, a request could charge the wrong account, or you find a similar security issue, [report it privately to Esquisse](https://github.com/EsquisseHQ/studio/security/advisories/new). Ordinary bugs, including a confusing price label, belong in [Issues](https://github.com/EsquisseHQ/studio/issues).

Include the affected page or component, the version or commit if known, what you observed and the potential impact. Use your own test data. Redact API keys, payment details and other people’s media.

The maintainer will use the private report to discuss the finding and coordinate a fix and any public advisory. If a real credential was exposed, revoke it with its provider as soon as possible.
