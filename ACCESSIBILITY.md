# Accessibility in Esquisse

Creators should be able to enter a prompt, read the quote, start a generation and find the receipt using a keyboard or a screen reader. These are design goals for the prototype. Its assistive technology coverage has yet to be verified.

If a barrier interrupts your work, [open a bug report](https://github.com/EsquisseHQ/studio/issues/new?template=bug.yml). Tell us what you were trying to do and where you got stuck. For example, “After I choose the image format with the keyboard, I can’t move focus back to the prompt.” Browser, device and assistive technology details are helpful when available. A written description is enough.
